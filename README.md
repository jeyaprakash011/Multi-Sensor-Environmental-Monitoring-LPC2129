# Multi-Sensor-Environmental-Monitoring-LPC2129
ARM7 LPC2129 based environmental monitoring system using temperature, LDR, soil moisture, and water sensors with LCD, UART, and LED status indication.
# Multi-Sensor Environmental Monitoring System

## Overview
An embedded environmental monitoring system developed using the ARM7 LPC2129 microcontroller. It monitors temperature, light intensity, soil moisture, and water detection to evaluate environmental conditions.

## Hardware Components
- LPC2129 (ARM7)
- LM35 Temperature Sensor
- LDR Light Sensor
- Soil Moisture Sensor
- Water Detection Sensor
- 16x2 LCD
- UART0 Serial Communication
- Green, Yellow, and Red LEDs

## Features
- Real-time temperature monitoring
- Light intensity monitoring
- Soil moisture measurement
- Water detection
- SAFE, WARNING, and WATER ALERT classification
- LCD-based monitoring
- UART terminal output
- LED-based status indication

## Technologies
- Embedded C
- ARM7
- LPC2129
- ADC
- GPIO
- UART
- LCD Interface

## Applications
Environmental monitoring, smart agriculture, soil moisture monitoring, and water detection systems.
